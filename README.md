# SobreMim

Site pessoal e (quase) portifólio de Samuel de Souza, com projetos, experiência e integrações com Last.fm, Steam e GitHub.
Desenvolvido em HTML, CSS e JavaScript puros e hospedado na Cloudflare Pages.

## Estrutura

```
Public/            tudo que vai pro ar
├─ index.html
└─ assets/
   ├─ css/style.css
   ├─ js/main.js
   ├─ js/modules/  céu, idade, konami
   └─ img/
scripts/           robô que atualiza os dados (em breve)
```
